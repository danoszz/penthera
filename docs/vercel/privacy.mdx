> **Project page.** For "what does the Penthera Vercel integration keep about me?"

Last updated: 7 November 2026

## Who is responsible

Daan van der Zwaag, the Netherlands, `security@penthera.org`, is the controller
for the data the integration keeps. Vercel is a separate, independent
controller for the data it handles on its own platform.

## What we keep

For each installation, and nothing else:

- Vercel's configuration id for the installation,
- your team id, or your user or account id for a personal account,
- a Vercel access token, encrypted (AES-256-GCM),
- the date of the latest install or transfer,
- a random value that ends old setup sessions after an install or a transfer,
  and
- for each project you turn the check on for, its project id and which
  installation turned it on, so a scan result reaches the right check.

## What reaches us for each production deploy

When the scan in your GitHub Actions ends, the workflow sends us three things:
the project id, the deployment id, and pass or fail. With them comes a token
that GitHub signs for your repository. It names the repository, the workflow
and its run, the commit, and the GitHub account that started the run. We use
it only to check that the result comes from the Penthera workflow in the repo
your project is connected to.

We then set the Penthera check's result in Vercel, and keep none of it: not the
ids, not the result, not the token. Our own logs hold an error code at most.

To keep the service working, we count anonymous daily totals: how many results
arrived that day, how many passed, failed, or were refused and why. The totals
are numbers under a date. They hold no project, deployment, team or
installation id and no IP address, so they cannot be tied to you. Each day's
totals are deleted after 90 days.

## What never reaches us

Your source code, deployment URLs, findings, GitHub access tokens, Vercel
protection bypass secrets, environment variables and email addresses.

To draw the setup pages, the server reads your shared projects' ids, names and
linked GitHub repositories from Vercel. It shows them to you and does not
store them.

## Why, and on what basis

To run the integration you asked for: register the check, pass each scan's
result on to it, and keep it working until you uninstall. The legal basis is the performance of a contract (GDPR
Art. 6(1)(b)).

## No tracking

No analytics beyond the anonymous daily totals above, no tracking, no
profiling, no advertising. We do not sell or
share your data. During the install we set two strictly necessary cookies: a
CSRF check (up to 30 minutes) and a setup session (30 minutes). Neither holds
your token.

## Where it runs, and who processes it for us

The data stays in the EU. The server's functions run in Frankfurt, Germany
(Vercel region `fra1`), and the records are stored in an EU region.

- Vercel Inc. hosts the server and keeps its request logs. Vercel is a US
  company, so its processing is covered by its own transfer safeguards, such as
  the EU-US Data Privacy Framework or standard contractual clauses.
- Upstash, through the Vercel Marketplace, stores the records listed above in
  an EU region.

Separately from the stored record, Vercel's request logs for the server record
each request's path and query string. That includes the one-time install code
(spent within seconds, usable once), the configuration id, your team id and
Vercel's return address. Vercel keeps these logs for the plan's default
period. On the Pro plan that is 1 day, or 30 days if Observability Plus is on,
as stated in Vercel's
[runtime logs documentation](https://vercel.com/docs/logs/runtime#limits). We
do not export or analyze them.

## How long

The anonymous daily totals: 90 days. Everything else, until you uninstall: Vercel tells us, and we delete the record and its project
links. Removing the check from a project deletes that project's link. A weekly
check also deletes any record whose token Vercel no longer accepts, and any
link whose installation is gone.

## Your rights

You can ask for access to or deletion of your data at `security@penthera.org`.
We answer within 30 days. Uninstalling deletes it without asking. You can
complain to the Autoriteit Persoonsgegevens, the Dutch data protection
authority.

## Security incidents

If a breach affects your data, we tell you and the Autoriteit Persoonsgegevens
as the GDPR requires, and Vercel within 48 hours, as our agreement with Vercel
requires.

## The scan itself

The scan runs in your GitHub Actions, not on our server. What it contacts is
described in Penthera's [privacy and network use](/privacy) page.

## Changes

We date every version. We give 30 days' notice of a material change on this
page and in the repository's
[changelog](https://github.com/danoszz/penthera/blob/main/CHANGELOG.md).
