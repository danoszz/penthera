section: Detection

- **A repo scan checks your GitHub Actions workflows.** Three rules from GitHub's guidance on securing workflows: `gha-pwn-request` (a `pull_request_target` or `workflow_run` workflow checks out the pull request's code), `gha-script-injection` (text an outsider writes reaches a `run:` script through `${{ }}`), and `gha-unpinned-action` (an action used by a movable tag instead of a commit SHA). It reads `.github/workflows/` as text, runs nothing, and points to the line. Every line is read, however long, and a workflow over 256 KB is reported as `gha-workflow-unchecked` instead of skipped, so padding can't hide a step. Penthera's own workflows pass all three.
