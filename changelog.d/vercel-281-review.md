section: Security

- **Four ways to hide a finding, closed.** In library mode, a ternary such as `flag ? (a) : (cmd) => exec(cmd)` was read as a typed arrow and took the arrow's parameters away, and a TypeScript conditional return type (`T extends U ? X : Y`) dropped the whole method; both are reported again, and so is a generic right after a function name (`function run<T>(`). A hook that pipes into `/usr/bin/env bash` or `sudo -u root bash` inside `"$(...)"` or a backtick in double quotes is found. `require("child_process") .exec(req.body.cmd)` with a space or a line break before the dot, or `require ("child_process")`, no longer hides a request-fed shell command. Found by Vercel Security Review.
- **Crafted files can't slow a scan down.** Deeply nested destructured parameters, nested assignments past the work budget, nested exported objects, and an unclosed regex character class repeated on one line each cost linear time now; a library file past its work budget is still reported as incomplete (exit 2). Found by Vercel Security Review.
